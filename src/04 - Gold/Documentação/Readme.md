# Documentação da Camada Gold

A camada Gold hoje tem uma única tabela: [`TB_FATO_MERCADO_CARTAS`](./TB_FATO_MERCADO_CARTAS/Readme.md), visão de mercado de cartas de Magic: The Gathering (catálogo + coleção + preço + esclarecimentos de regras).

As 3 tabelas Gold anteriores (`TB_ANALISE_MERCADO_CARTAS_EXECUTIVO`, `TB_METRICAS_PERFORMANCE_INVESTIMENTOS`, `TB_REPORT_ALERTAS_EXECUTIVOS`) apontavam para colunas/tabelas Silver em inglês que não existem mais desde a renomeação DAMA-DMBOK (#115/#116) e foram removidas.
