# Documentação da Camada Gold

A camada Gold tem duas tabelas:

- [`TB_FATO_MERCADO_CARTAS`](./TB_FATO_MERCADO_CARTAS/Readme.md): visão de mercado de cartas de Magic: The Gathering (catálogo + coleção + preço + esclarecimentos de regras + migrações de ID), 1 linha por cotação.
- [`TB_DIM_CARTAS`](./TB_DIM_CARTAS/Readme.md): atributos atuais de cada carta, base da fato.
